# 🛒 Shopping List App

간단한 쇼핑 리스트 웹 앱입니다. 별도 백엔드나 빌드 과정 없이 `index.html` 하나로 동작합니다.

## Features

- 아이템 추가 / 삭제
- 체크박스로 완료 표시
- 완료(체크)된 항목 일괄 삭제
- 남은 항목 수 표시
- `localStorage`를 이용한 데이터 저장 (새로고침해도 유지)

## Usage

`index.html` 파일을 브라우저에서 열기만 하면 바로 사용할 수 있습니다. 별도 설치나 서버 실행이 필요 없습니다.

## Tech Stack

- HTML / CSS / Vanilla JavaScript
- 브라우저 `localStorage` API
